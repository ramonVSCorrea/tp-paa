# 📚 Trabalhos Práticos - Projeto e Análise de Algoritmos (PAA)

Este repositório contém os trabalhos práticos desenvolvidos para a disciplina de **Projeto e Análise de Algoritmos (PAA)**, implementando estudos comparativos de algoritmos clássicos da Ciência da Computação.

## 📂 Projetos

### [📊 TP I - Estudo Comparativo de Algoritmos Quicksort](./paa_tp_quick_sort)

Estudo comparativo abrangente de três variações do algoritmo Quicksort, incluindo:
- **Quicksort Recursivo** - Implementação tradicional recursiva
- **Quicksort Híbrido** - Versão que usa Insertion Sort para subarrays pequenos
- **Quicksort Híbrido Melhorado** - Versão aprimorada com técnica mediana-de-três

**🔗 [Acessar TP I - Quicksort](./paa_tp_quick_sort)**

---

### [🎒 TP II - Problema da Mochila 0/1 (Knapsack Problem)](./paa_tp_ii)

Implementação e comparação de diferentes abordagens algorítmicas para o Problema da Mochila 0/1:
- **Programação Dinâmica Clássica** - Solução exata com matriz 2D
- **Programação Dinâmica Otimizada** - Solução exata com otimização de espaço (1D)
- **Algoritmo Guloso** - Solução aproximada baseada em razão valor/peso

**🔗 [Acessar TP II - Knapsack](./paa_tp_ii)**

- **🏗️ Clean Architecture** - Separação clara de responsabilidades em camadas
